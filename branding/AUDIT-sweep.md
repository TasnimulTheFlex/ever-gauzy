# Final Base360 branding sweep

Date: 2026-10-21. Branch: `base360`. Read the brand sheet and all four area audits before editing.

## What changed

- Rebranded the previously unowned MCP server: advertised server IDs/names, version information, authentication and connection tool descriptions, errors, transport status bodies and logs. Production trusted origins now contain the configured API URL and `https://time-api.base360.ai`; the six bundled upstream origins were removed. Env names, tool IDs and exported classes remain compatible.
- Standardized publisher metadata in 140 package manifests: Base360 author/support/website, fork repository/bugs URLs, descriptions, keywords and installer copyright fields. Kept every npm package name, dependency reference, script and export unchanged. Also updated the workspace and changelog repository metadata.
- Fixed merged server-installer metadata: explicit executable names, macOS bundle/display names, Windows publishers and protocol registrations for Server, API Server and MCP Server, matching the existing branding regression test.
- Finished worker, seed-cleanup, AI, plugin upload and CLI messages; rebranded the webhook delivery user agent. Changed changelog migration presentation links/copy while keeping the exact historical title lookup that removes old seeded announcements. Updated stale web/demo and desktop test fixtures, app IDs/protocols and the splash fallback. Desktop/web tracing targets now use the Base360 API.
- Optional platform connections and anonymous statistics have no upstream destination by default: operators must supply `EVER_PLATFORM_API_URL` or `EVER_STATS_API_URL`. Consent links accept the Base360 web host or the configured platform domain. Existing SDK contracts, signatures, headers, wire IDs and security guards remain intact. The displayed schema link points to this fork's schema module.
- Updated deployment templates, proxies, certificate contact addresses, Zapier redirect-domain defaults, issue/support links, image references and CI presentation metadata. Legacy image publishers now target this fork's GHCR namespace, retain demo/stage suffixes, and no longer authenticate/push to upstream Docker Hub or DigitalOcean registries. The CDN mirror reads this fork's releases and requires a validated operator-provided `R2_PUBLIC_URL`. Root README is a short Base360 quick start with legal/source links.
